# 💡 Lamp Login Animation

An interactive login form animation built using **HTML, CSS, and JavaScript**.

Pull the lamp's hanging cord down with your mouse or finger to turn on the lamp and reveal the login form. 💡✨

## 🌐 Live Demo

👉 [View Live Demo](https://sahiru-03.github.io/Lamp-login-animation/)

## ✨ Features

- 💡 Interactive lamp
- 🖱️ Drag-and-pull lamp cord
- ✨ Smooth lamp glow animation
- 🔐 Animated login form
- 🪟 Glassmorphism UI
- 📱 Responsive design
- 🖥️ Mouse and touch support
- ⚡ Pure HTML, CSS and JavaScript
- 🚫 No external libraries required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
